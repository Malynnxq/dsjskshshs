# Meal Counter

A small browser-based meal counter. Create named meals, add any value from 0 to 1 to each meal's running total, and delete meals when they are no longer needed.

## Features

- Accepts decimal points and decimal commas (`0.25` or `0,25`)
- Rejects values below 0 or above 1
- Keeps an independent running total for every meal
- Saves meals and totals in the browser with `localStorage`
- Responsive, accessible interface with no build step

## Run locally

Open `index.html` in a browser, or serve the directory with any static file server.
